SHORT STORY FOR CLIENTS
================================================================================

1. Studio creates a customer and gallery, uploads photos, marks it ready.
2. Client gets notified, logs in (or uses share code), views and selects photos.
3. Studio gets album requests and enquiries in the dashboard.
4. Public site markets the studio (portfolio, services, contact).


================================================================================
HOSTING NOTES (FROM CHAT)
================================================================================

Demo hosting:
- Render free tier works well for client demos (Django + Postgres).
- Netlify alone does NOT run full Django — use Render (or EC2) for the app.
- Free Render may sleep after ~15 min idle (first load ~30–60 seconds).
- Free Postgres on Render expires after 30 days — OK for short demos.
- Gallery uploads on demo: use S3 (USE_S3=True) — no persistent disk on free Render.

Production path:
- Same codebase can move from Render demo → EC2 without rewrite.

Demo logins (after seed_demo):
- Studio admin: admin / admin123  → /studio/
- Photographer:  elise / studio123 → /studio/
- Client:        client / client123 → /client/
